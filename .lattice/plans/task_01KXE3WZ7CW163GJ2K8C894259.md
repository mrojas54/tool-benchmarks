# TB-31: --exclude-subagents is a silent no-op on the agentsview index path, and the Summary claims an exclusion that never happened

TB-29 fixed --exclude-subagents on the RAW path (is_subagent path detection). The
AGENTSVIEW path was never covered, and there the flag does nothing at all.

MEASURED (live archive, --agent claude --all --limit 40, 2026-07-13):

  raw path (TB-29 fix works):
    [none]                620 calls, fingerprint 332fff82da4be971
    [--exclude-subagents] 521 calls, fingerprint 5c3854a59d2c2641   <- moves, correct

  agentsview path (no-op):
    [none]                3251 calls, fingerprint 6d146170ac125aff
    [--exclude-subagents] 3251 calls, fingerprint 6d146170ac125aff  <- IDENTICAL

Identical call count AND identical corpus fingerprint with the flag on and off:
nothing was excluded. But the Summary still flips its provenance line to
'Subagents included: no' -- an unearned claim. The report asserts an exclusion
that demonstrably did not occur.

ROOT CAUSE: shares TB-30's root cause. Without --include-children, agentsview never
LISTS subagent/child sessions, so no ref ever carries is_subagent=True and the
filter has nothing to remove. TB-29 hardened the predicate; this path never
receives the rows to apply it to.

NOTE ON ORDERING: fixing TB-30 (passing --include-children) is necessary but likely
not sufficient -- once child sessions are listed, is_subagent must actually be
derived for agentsview-sourced refs, which have path=None and so cannot use the
raw path's '<project>/<session-uuid>/subagents/' path-segment detection. The
agentsview row shape must supply the signal (e.g. a parent/child field on the
session-list JSON). Fix TB-30 first, then re-run this A/B: if the fingerprint still
does not move, the is_subagent derivation is the remaining gap.

FIX: after TB-30, derive is_subagent for agentsview refs from the session-list
payload, and assert in tests that --exclude-subagents moves the fingerprint on BOTH
index sources (the TB-29 test asserted on the FILTERED refs -- mirror that here).
The 'Subagents included:' provenance line should reflect what was actually filtered,
not merely which flag was passed.
